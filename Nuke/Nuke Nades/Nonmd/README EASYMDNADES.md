
Quick Links CSV has the following format 

`Title,Map,Type,Tags,Link`

- Title is a String of any arbitrary length, no commas pls

- Map
- Type
	- Nade
		- Nade lineups 
	- Exec
		- Execs. Parsing to be done later 
	- Tip
		- Like Tips & Tricks
		- Could be boosts, teamplays, etc 
- Tags
	- IN QUOTES (if type == nade)
		- "(SIDE, GRENADE TYPE)"
	- If not type == nade then just the side 
- Link
	- Youtube
